# Manual da Comunidade

Este repositório foi criado como parte do primeiro desafio de squad do Bootcamp de Desenvolvimento Back-end com .NET.

O objetivo da atividade é praticar o fluxo de colaboração com Git e GitHub, incluindo Issues, branches, commits, Pull Requests, Code Review e merge.

## Arquivos do manual

- [Sobre a comunidade](sobre.md)
- [Perguntas frequentes](faq.md)
- [Contato](contato.md)
- [Código de Conduta](codigo-de-conduta.md)

## Colaboração

Cada integrante da squad é responsável por um dos arquivos do manual.

As alterações são desenvolvidas em branches individuais, revisadas por outra integrante e integradas à branch `main` por meio de Pull Requests.
